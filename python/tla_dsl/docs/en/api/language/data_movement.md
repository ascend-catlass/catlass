# Data Movement

[Language Reference](index.md) | [API Quick Reference](../quick_reference.md)

Tensor copies between on-chip and global memory, and UB register load/store.

## `tla.copy`

**Source:** [`catlass.core_api.copy`](../../../../catlass/core_api.py)

Description:

Copy a tile from `src` to `dst`. Supported routes and dtypes are listed
after Constraints.

Prototype:

```python
tla.copy(dst: Tensor, src: Tensor, params: CopyParams | None = None, *, scale: Tensor | None = None, cache_policy: CachePolicy | None = None) -> None
```

Parameters:

- `dst` (`Tensor`): Destination tile. Required.
- `src` (`Tensor`): Source tile. Required.
- `params` (`CopyParams | None`): Path-specific params:
  `CopyL0C2DstParams`, `CopyUbToGmParams`, `CopyPadParams` (GM→UB
  DataCopyPad). Default `None`.
- `scale` (`Tensor | None`): L1 OCP `e8m0` shared-exponent tile for
  L1→L0A/L0B MX load. Stored as `i8`/`u8`; destination tag is
  `tla.arch.zZMxScale` (L0A) or `tla.arch.nNMxScale` (L0B).
  Default `None`.
- `cache_policy` (`CachePolicy | None`): Optional L2 cache hint for the
  GM endpoint of this copy (`DISABLE` / `NORMAL`). On `GM→*` routes it
  tags the GM src; on `*→GM` routes it tags the GM dst. There is no
  GM→GM copy route. Default `None` (omit the hint; BC uses NORMAL).
  On non-GM routes any explicit value (including `NORMAL`) is rejected;
  omit the argument instead.

Constraints:

- Must be called inside a `@tla.kernel`-decorated kernel function.
- Must be called inside `tla.cube()` or `tla.vector()`.
- Copy size follows each tile's `origin_shape`.
- `CopyPadParams` is GM→UB RowMajor only (f32/f16/bf16/i32/u32/i16/u16/
  i8/u8). `left_padding` / `right_padding` / `padding_value` may be
  runtime integer/index SSA. When a side count is a static int, pad
  bytes must be ≤ 32B; when extents are also static, dst innermost
  origin must be ≥ src + left_padding + right_padding.
- On Ascend 950, two logical rank-3 views `(B, M, N)` select batched
  GM-to-L1 layout conversion. FP8 supports RowMajor→zN and
  ColumnMajor→nZ; E8M0 supports the four GM MX-scale routes below.
  Batch count is `origin_shape[0]`; source and destination matrix
  strides are each layout's leading stride, in elements. Inner strides
  retain their 2-D meaning. Both logical extents must match, including
  runtime values. Zero batches or zero matrix extents perform no DMA.
  Other rank-3 layout/dtype combinations fail at compilation instead
  of falling back to a 2-D copy.
- Batched copies require `params=None` and `scale=None`, a batch count
  in 0..65535, and positive destination batch strides aligned to 32
  bytes and at most 65535 32-byte blocks. E8M0 source matrix strides
  must preserve exponent pairs. Runtime geometry must satisfy the same
  constraints. The caller supplies enough backing storage and disjoint
  destination matrices; interleaved NZ layouts are permitted.
- Packed fp4 is staged as bytes on the routes that convert the
  descriptor before copying -- GM->UB, UB->GM and UB->L1 -- so each
  tile's innermost `origin_shape`, its innermost origin coordinate and
  the stride the conversion halves must all be even: two fp4 elements
  share a byte, and an odd one of the three lands half a byte off. The
  halved stride is the row stride of a `RowMajor` tile and the pitch
  between C0 columns of a `zN` tile, so a `zN` destination on UB->L1
  carries the requirement as well. A value known only at run time
  cannot be shown to be even and is refused as well. The cube's GM->L1
  fp4 route keeps its own denomination and is unconstrained, and
  `tla.experimental.mx_to` still accepts an odd extent -- such a tile
  simply cannot be staged through a byte descriptor.
- `scale` is only valid on L1→L0A/L0B; the loaded tile must then be
  consumed by `tla.mmad_mx`.
- For MX scale destinations (`zZMxScale` / `nNMxScale`), the source
  tile must span full L1 rows; stack scale blocks along rows.
  Checked only when row pitch is statically known.
- UB→UB counts in whole 32-byte blocks; rows round up. Rejected if the
  origin is not 32B-aligned, or multi-row pitch cannot hold the rounded
  row. Destination tagged `ColumnMajor` is a transpose: tile shape must
  be whole 16×C0 blocks, or 32×32 for 1-byte types.
- `GM`→`L1` / `L1`→`biasbuf` contiguous runs use rank-1 `VectorLayout`;
  multi-row bias tiles are not representable — slice one row.
- PER_CHANNEL dequant parameters (`CopyL0C2DstParams.quant_tensor`)
  are a rank-1 `VectorLayout` tile in the `L1` address space, element
  type `u64`, unit stride. One element carries the dequant parameter
  shared by every element of one output channel, so the run must hold
  exactly one element per channel of the destination tile, ``originShape[1]``
  after `tile_view` cropping. When both lengths are static, a mismatch
  fails compilation.
- **Prepacked `GM` tiles:** a buffer already packed in fractal order is
  tagged `zN` (or `nZ` for the transposed packing) and copied to the
  matching `L1` tile with no re-layout. Only the aligned `zN` / `nZ` are
  `GM` source tags — the tight M-axis is `zNUnAlign` on the `UB`→`L1`
  route, and the `GM` `zNUnAlign` route is the NC1HWC0 feature map that
  feeds `tla.experimental.img2col`. Size both ends for the padded tile:
  `ceil(M/16) * 16` rows for `zN`, and `ceil(M/C0) * C0` rows by
  `ceil(N/16) * 16` columns for `nZ`, since the block move walks whole
  fractals and the last row group travels in full.
- Whole-tile DMA uses `tla.copy`. For register-level UB unaligned
  access, use `tensor.load` / `tensor.store` with `UnalignLoadParams` /
  `UnalignStoreParams`.
- **Shapes not aligned to 32 bytes:** C0 is 32 bytes. For ND GM↔UB,
  prefer a leading dimension whose byte size is a multiple of 32.
  Otherwise keep `origin_shape` as the real size and enlarge the
  physical layout, or use unaligned load/store.

Example:

```python
# --- 1) Aligned GM ↔ UB (RowMajor, 32B-friendly) ---
with tla.vector():
    tla.copy(dst=x_ub, src=x_gm)
    tla.copy(
        dst=x_ub,
        src=x_gm,
        cache_policy=tla.params.CachePolicy.DISABLE,
    )  # optional L2 hint on GM src
    tla.copy(dst=y_gm, src=y_ub)

# --- 2) ND → zN: GM RowMajor → L1 zN ---
l1_a = tla.make_tensor_like(l1_ptr, gm_a, layoutTag=tla.arch.zN)
with tla.cube():
    tla.copy(dst=l1_a, src=gm_a)

# --- 3) M not a multiple of 16: zNUnAlign ---
# Before: rows may be runtime and not a multiple of 16.
l1_unalign = tla.make_tensor_like(l1_ptr, gm_tile, layoutTag=tla.arch.zNUnAlign)
with tla.cube():
    tla.copy(dst=l1_unalign, src=gm_tile)

# Batched FP8: both tensor layouts carry the batch geometry.
# src_step and dst_step are independent element strides.
src3 = tla.make_tensor(src_ptr, tla.make_layout(
    tla.make_shape(batch_count, valid_rows, 128),
    tla.make_stride(src_step, 128, 1)))
dst3 = tla.make_tensor(dst_ptr, tla.make_layout(
    tla.make_shape(batch_count, (16, 8), (32, 4)),
    tla.make_stride(dst_step, (32, 512), (1, 4096)),
    origin_shape=tla.make_shape(batch_count, valid_rows, 128),
    layoutTag=tla.arch.zN))
with tla.cube():
    tla.copy(dst3, src3)

# --- 4) Prepacked GM zN: a plain block move, no re-layout ---
# The host buffer is already zN-packed and padded to ceil(M/16) * 16 rows.
# Both ends carry the same tree, so the copy reorders nothing.
gm_zn = tla.make_tensor(
    gm_ptr, tla.make_layout_with_tag((m_pad16, k), dtype_a, tla.arch.zN)
)
l1_zn = tla.make_tensor_like(l1_ptr, gm_zn, tla.arch.zN)
with tla.cube():
    tla.copy(dst=l1_zn, src=gm_zn)

# --- 5) Prepacked GM nZ: the transposed packing, same idea ---
# nZ pads both axes -- ceil(M/C0) * C0 rows by ceil(N/16) * 16 columns --
# and the copy steps whole C0-row groups, so both buffers carry it.
gm_nz = tla.make_tensor(
    gm_ptr, tla.make_layout_with_tag((m_pad_c0, n_pad16), dtype_a, tla.arch.nZ)
)
l1_nz = tla.make_tensor_like(l1_ptr, gm_nz, tla.arch.nZ)
with tla.cube():
    tla.copy(dst=l1_nz, src=gm_nz)

# --- 6) Flat contiguous run: VectorLayout ---
# A 1-N bias row is one run of elements, not a (1, N) tile. Both
# endpoints of the staging pipeline carry the same tag: GM -> L1 first,
# then L1 -> the bias table buffer.
gm_bias = tla.tile_view(gm_bias_full, tla.make_shape(n), tla.make_coord(0))
l1_bias = tla.make_tensor_like(l1_bias_ptr, gm_bias, tla.arch.VectorLayout)
l0_bias = tla.make_tensor_like(l0_bias_ptr, l1_bias, tla.arch.VectorLayout)
with tla.cube():
    tla.copy(dst=l1_bias, src=gm_bias)
    tla.copy(dst=l0_bias, src=l1_bias)
    tla.mmad(l0_c, l0_a, l0_b, init_c=True, unit_flag=0, bias=l0_bias)

# Related (register path, not tla.copy): unaligned UB ↔ vector register
#   with tla.vec.func(mode="simd"):
#       x_reg = x_ub.load(tla.params.UnalignLoadParams())
#       y_ub.store(y_reg, tla.params.UnalignStoreParams())
```

## `tla.Tensor.load`

**Source:** [`catlass.tla.tensor._Tensor.load`](../../../../catlass/tla/tensor.py)

Description:

Load this UB tensor tile into vector or mask SSA (`tile.load`).

Prototype:

```python
tla.Tensor.load(params: LoadParams | None = None) -> MaskSSA | VectorSSA | tuple[VectorSSA, VectorSSA] | tuple[VectorSSA, _Tensor]
```

Parameters:

- `params` (`LoadParams | None`): Load mode. Optional, default `None`.
  - `None` / `NormalLoadParams` / `UnalignLoadParams` /
    `BlockLoadParams` → `VectorSSA` (or a pair for
    `DIST_DINTLV_B8` / `DIST_DINTLV_B16` / `DIST_DINTLV_B32`).
  - `MaskLoadParams` → `MaskSSA`.
  - `NormalLoadParams`:
    - `load_dist` (`str`): `tla.params.LoadDist` token. Default
      `DIST_NORM`.

      | Value | Meaning |
      |---|---|
      | `DIST_NORM` | Default contiguous load |
      | `DIST_BRC_B8` | Broadcast one b8 element to all 256 lanes |
      | `DIST_BRC_B32` | Broadcast one b32 element to all lanes |
      | `DIST_DINTLV_B8` | Load 512 bytes; even/odd b8 elements fill two 256-lane vectors |
      | `DIST_DINTLV_B16` | Load 512 bytes; return two 128-lane b16 registers, even positions first and odd positions second |
      | `DIST_DINTLV_B32` | f32 deinterleave; dual results |
      | `DIST_US_B8` / `DIST_US_B16` | 2x up-sample |
      | `DIST_DS_B8` / `DIST_DS_B16` | Load 512 bytes and retain every other b8/b16 element into one full vector |
      | `DIST_BRC_B16` | Broadcast one b16 element |
      | `DIST_UNPACK_B8` | Load 128 b8 elements; insert one zero byte after each into a 256-lane vector |
      | `DIST_UNPACK_B16` | Zero-extend b16 to double width |
      | `DIST_UNPACK_B32` | Load 32 b32 elements; insert one zero b32 element after each into a 64-lane vector |
      | `DIST_UNPACK4_B8` | Load exactly 64 bytes into register byte slots 0,4,...,252; zero the other register bytes |
      | `DIST_E2B_B16` / `DIST_E2B_B32` | Element-to-DataBlock broadcast |
      | `DIST_BLK` | One 32-byte DataBlock broadcast to all 8 |

    - `post_mode` (`str`): `POST_MODE_NORMAL` (default) or
      `POST_MODE_UPDATE`.
    - `post_update_stride` (`Any`): Element stride when
      `post_mode=POST_MODE_UPDATE`; `0` advances by `tile_extent`
      (`origin_shape`). Default `0`.
  - `UnalignLoadParams`:
    - `post_mode` (`str`): `POST_MODE_NORMAL` (default) or
      `POST_MODE_UPDATE`.
    - `post_update_stride` (`Any`): `0` (default) advances by
      `origin_shape`; effective stride must be in `(0, VL]`. Default `0`.
  - `BlockLoadParams`:
    - `block_stride` (`int`): Heads apart in 32B DataBlocks; `0`
      repeats the first block into all 8 slots. Default `0`.
    - `post_mode` (`str`): `POST_MODE_NORMAL` (default) or
      `POST_MODE_UPDATE`.
    - `repeat_stride` (`Any`): Compile-time pre-offset in 32B
      blocks; with `POST_MODE_UPDATE`, the post-update stride.
      Default `0`.
  - `MaskLoadParams`:
    - `load_dist` (`str`): `tla.params.MaskLoadDist` token.
      Default `DIST_NORM`.

      | Value | Meaning |
      |---|---|
      | `DIST_NORM` | Bit-packed mask load |
      | `DIST_US` | Bit upsample |
      | `DIST_DS` | Bit downsample |

Constraints:

- Must be called inside a `@tla.kernel`-decorated kernel function.
- Must be called inside `tla.vec.func(mode="simd")`; source tile must be UB.
- The actual read range must stay within the usable UB address space.
- Mask load ``DIST_NORM`` requires a 1/2/4-byte scalar UB element type.
- Distribution modes fix the element width: `DIST_US_B8` needs
  i8/u8; `DIST_BRC_B16` / `DIST_US_B16` / `DIST_UNPACK_B16` /
  `DIST_E2B_B16` need 2-byte (f16/bf16/i16/u16); `DIST_E2B_B32`
  needs 4-byte (f32/i32/u32); `DIST_DINTLV_B16` needs 2-byte
  (f16/bf16/i16/u16); `DIST_DINTLV_B32` needs f32;
  `DIST_BLK` works for any element size.
- `DIST_DINTLV_B8` supports i8/u8/f8E4M3FN/f8E5M2/HiFloat8/E8M0 and packed
  Float4E2M1x2/Float4E1M2x2. Each register
  holds 256 one-byte elements; one load reads `2 * 256 = 512` bytes
  and returns two full vectors of the source type, even positions
  first and odd positions second. For input `[a0, a1, a2, a3, ...]`,
  the results are `[a0, a2, ...]` and `[a1, a3, ...]`. The source
  address must be 32-byte aligned and all 512 bytes must be valid,
  independently of the tile shape. For FP4x2, each element is one byte
  holding two FP4 values. The load deinterleaves these packed bytes
  without changing their two nibbles; each result holds 256 packed
  elements (512 FP4 values). E8M0 is transported as raw bytes, including
  the 0xFF NaN encoding, and can be written back with a normal aligned
  store; arithmetic and register casts are unsupported. Logical FP4
  and Bool are not supported by this distribution.
- `DIST_DINTLV_B16` requires a 32-byte-aligned source address.
- `DIST_UNPACK4_B8` requires a 1-byte element type and a
  32-byte-aligned source address.
- `DIST_BRC_B8` / `DIST_DS_B8` / `DIST_UNPACK_B8` support
  i8/u8/f8E4M3FN/f8E5M2; `DIST_DS_B16` supports
  f16/bf16/i16/u16; `DIST_UNPACK_B32` supports f32/i32/u32.
  These modes preserve the source element type and produce full
  256-byte vector registers.
  `DIST_BRC_B8` requires 1-byte source alignment; the other four
  require 32-byte alignment. `DIST_UNPACK_B8` / `DIST_UNPACK_B32` read 128 bytes;
  DS reads 512 bytes. The caller must provide the
  complete valid source range, independently of the tile shape.
- `BlockLoadParams` follows AscendC ``DATA_BLOCK_COPY``
  (b8/b16/b32; b8 includes i8/u8, Bool as b8);
  `block_stride` and `repeat_stride` must fit in [0, 65535].
- ``DIST_US`` / ``DIST_DS``: UB element type may be any
  b8/b16/b32/b64 scalar. The element type only types the UB
  address; the mask bit layout does not depend on element width.
  When the static tile-shape product is in ``{32,64,128,256}``,
  it is used as ``N`` on ``!tla.mask<N>``; otherwise ``N=256``.
- Mask load byte-offset alignment (UB byte address =
  base + offset×sizeof(T)): ``DIST_NORM`` → ``VL/8``;
  ``DIST_US`` → ``VL/16``; ``DIST_DS`` → ``min(32, VL/4)``.
  On VL=256 this is 32B / 16B / 32B.
- `POST_MODE_UPDATE` requires a rank-1 contiguous tile,
  `DIST_NORM`, and element type in `{f16, bf16, f32}`. Returns
  `(vector, next_tile)`. Inside `tla.vec.func`, assign
  `next_tile` back with `tla.range` (`while` is not supported
  nested in `vec.func`). The window must already be an origin
  tile (`coord=0`); cut it with `tile_view` (or equivalent).
  UPDATE never automatically folds non-zero coordinates.
  `NormalLoadParams`: `post_update_stride=0` (default) advances
  by `tile_extent` (`origin_shape`); an explicit stride keeps
  fill / stride-advance decoupling. `UnalignLoadParams`: default
  `0`→`tile_extent`; effective stride must be in `(0, VL]`. On a clean
  `tla.range`, `tla-unalign-ureg` hoists Pre/Post outside the for;
  `for`⊃dynamic `if` keeps per-trip dual-instr.

Example:

```python
with tla.vec.func(mode="simd"):
    x_reg = x_ub.load()
    x_unalign = x_ub.load(tla.params.UnalignLoadParams())
    x_blk = x_ub.load(tla.params.NormalLoadParams(
        load_dist=tla.params.LoadDist.DIST_BLK))
    x_gather = x_ub.load(tla.params.BlockLoadParams(block_stride=4))
    preg = mask_ub.load(
        tla.params.MaskLoadParams(load_dist=tla.params.MaskLoadDist.DIST_DS)
    )
    y = tla.where(preg, x_reg, min_reg)
    # fp8_ub: 64 Float8E4M3FN elements at a 32-byte-aligned address.
    fp8_reg = fp8_ub.load(tla.params.NormalLoadParams(
        load_dist=tla.params.LoadDist.DIST_UNPACK4_B8))
    fp32_reg = fp8_reg.to(tla.Float32)
```

## `tla.Tensor.store`

**Source:** [`catlass.tla.tensor._Tensor.store`](../../../../catlass/tla/tensor.py)

Description:

Store vector or mask SSA into this UB tensor tile (`tile.store`).

Prototype:

```python
tla.Tensor.store(value: VectorSSA | MaskSSA, params: StoreParams | None = None, *, mask: MaskSSA | None = None) -> _Tensor | None
```

Parameters:

- `value` (`VectorSSA | MaskSSA`): `VectorSSA` or `MaskSSA` to store.
  Required.
- `params` (`StoreParams | None`): Store mode. Optional, default
  `None`.
  - `None` / `NormalStoreParams` / `UnalignStoreParams` /
    `BlockStoreParams` → vector store.
  - `MaskStoreParams` → mask store.
  - `NormalStoreParams`:
    - `store_dist` (`str`): `tla.params.StoreDist` token. Default
      `DIST_NORM`.

      | Value | Meaning |
      |---|---|
      | `DIST_NORM` | Default contiguous store |
      | `DIST_PACK4_B32` | Store register byte slots 0,4,...,252 to UB byte slots 0,1,...,63, subject to the mask |
      | `DIST_FIRST_ELEMENT_B8` | Write only lane 0 (1-byte) |
      | `DIST_FIRST_ELEMENT_B16` | Write only lane 0 (2-byte) |
      | `DIST_FIRST_ELEMENT_B32` | Write only lane 0 (4-byte) |

    - `post_mode` (`str`): `POST_MODE_NORMAL` (default) or
      `POST_MODE_UPDATE`.
    - `post_update_stride` (`Any`): Element stride when
      `post_mode=POST_MODE_UPDATE`; `0` advances by `tile_extent`
      (`origin_shape`). Default `0`.
  - `UnalignStoreParams`:
    - `post_mode` (`str`): `POST_MODE_NORMAL` (default) or
      `POST_MODE_UPDATE`.
    - `post_update_stride` (`Any`): `0` (default) advances by
      `origin_shape`; effective stride must be in `(0, VL]`. Default `0`.
  - `BlockStoreParams`:
    - `block_stride` (`int`): Heads apart in 32B DataBlocks.
      Default `0`.
    - `post_mode` (`str`): `POST_MODE_NORMAL` (default) or
      `POST_MODE_UPDATE`.
    - `repeat_stride` (`Any`): Used with `POST_MODE_UPDATE` as the
      post-update stride in 32B blocks. Default `0`.
  - `MaskStoreParams`:
    - `store_dist` (`str`): `tla.params.MaskStoreDist` token.
      Default `DIST_NORM`.
- `mask` (`MaskSSA | None`): Optional predicate for vector stores;
  rejected by `MaskStoreParams` and first-element modes. Default
  `None`. For `DIST_PACK4_B32`, masks use source lanes:
  4/2/1 lanes per destination byte for 1/2/4-byte sources.
  An omitted mask follows the destination's valid length;
  an explicit mask is not clipped to that length. Masked-out
  destination bytes remain unchanged.

Constraints:

- Must be called inside a `@tla.kernel`-decorated kernel function.
- Must be called inside `tla.vec.func(mode="simd")`; destination tile must be UB.
- `DIST_PACK4_B32` requires 1/2/4-byte source elements,
  1-byte destination elements and a 32-byte-aligned destination address.
  It stores at most 64 bytes, subject to the mask, without numeric
  conversion or FP4 nibble packing. For FP32→FP8 results, use
  `RegSlot.ZERO` to place the values in byte slots 0,4,...,252.
- First-element modes require the stored value and the dest tile to
  use the suffix-matching element width (b8 → 1-byte, b16 → 2-byte,
  b32 → 4-byte); passing a predicate mask raises an error.
- `POST_MODE_UPDATE` requires a rank-1 contiguous tile,
  `DIST_NORM`, and element type in `{f16, bf16, f32}`; returns the
  next tile. Inside `tla.vec.func`, assign it back with
  `tla.range`. Same origin window (`coord=0`) contract as UPDATE
  `load`. `NormalStoreParams`: default `post_update_stride=0`
  advances by `tile_extent` (`origin_shape`); an explicit stride is
  decoupled. `UnalignStoreParams`: default `0`→`tile_extent`;
  effective stride must be in `(0, VL]`; clean for hoists Pre/Post.

Example:

```python
with tla.vec.func(mode="simd"):
    y_ub.store(y_reg)
    y_ub.store(y_reg, tla.params.UnalignStoreParams())
    y_ub.store(y_reg, tla.params.NormalStoreParams(
        store_dist=tla.params.StoreDist.DIST_FIRST_ELEMENT_B16))
    # fp32_reg: 64 FP32 lanes; fp8_ub: 64 Float8E4M3FN elements.
    # fp8_ub starts at a 32-byte-aligned address.
    fp8_reg = fp32_reg.to(tla.Float8E4M3FN, tla.params.CastParams(
        round_mode=tla.params.RoundMode.CAST_RINT,
        sat_mode=tla.params.SatMode.SAT,
        reg_slot=tla.params.RegSlot.ZERO))
    fp8_ub.store(fp8_reg, tla.params.NormalStoreParams(
        store_dist=tla.params.StoreDist.DIST_PACK4_B32))
```

## `tla.Tensor.fill`

**Source:** [`catlass.tla.tensor._Tensor.fill`](../../../../catlass/tla/tensor.py)

Description:

Fill this L1 tile with a numeric constant.

Prototype:

```python
tla.Tensor.fill(value: int | float) -> None
```

Parameters:

- `value` (`int | float`): Trace-time scalar, encoded in the
  destination type. Integer destinations require an in-range
  `int`; f16/bf16/f32 destinations accept `int` or `float` and
  reject finite overflow. FP4/FP8 require finite values exactly
  representable in the destination format; out-of-range and inexact
  constants are rejected without rounding. E8M0 requires an exact
  positive power of two in ``[2**-127, 2**127]``; zero, negative
  values and non-powers of two are rejected.

Constraints:

- Must be called inside a `@tla.kernel`-decorated kernel function and
  nested inside `tla.cube()`.
- Destination must be an L1 tensor. Operand types use ``zN`` or
  ``nZ``; E8M0 scales use ``zZMxScale`` or ``nNMxScale``.
- Fill covers ``[coord, coord + origin_shape)``. Operand C0-axis
  boundaries are aligned up to 32-byte units. MX scales align
  the M/N axis to 16 and the scale-group axis to 2; each 16-by-2
  fractal occupies 32 bytes. A partial leading unit is left
  untouched; the final unit may include physical Padding beyond
  the logical extent, which must fit the allocation. Empty
  regions perform no writes.
- Supported element types: ``i16/u16/f16/bf16/i32/u32/f32``,
  packed fp4/fp8 operands
  (``f4e2m1``/``f4e1m2``/``f8e4m3fn``/``f8e5m2``), and ``f8e8m0``.
  8-bit integer destinations are not supported.

Example:

```python
# Zero the K-pad tail of an L1 A tile: tile first, then fill.
pad = tla.get_tile(t_l1a, tla.make_coord(0, k_valid),
                   tla.make_shape(m, k_l0 - k_valid))
pad.fill(0)
# Numeric one is encoded by the destination dtype.
t_l1a.fill(1.0)
t_l1sa.fill(1.0)  # E8M0 scale one, encoded as 0x7f.
```

tla.Tensor.__getitem__(crd: Any) -> Any
