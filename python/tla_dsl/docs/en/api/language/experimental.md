# Experimental APIs

[Language Reference](index.md) | [API Quick Reference](../quick_reference.md)

APIs under `tla.experimental` may change or be removed without backward-compatibility guarantees. Use the ordinary `tla.kernel` and `tla.jit` decorators; this namespace does not select another compiler.

## `tla.experimental.mx_to`

**Source:** [`catlass.tla.experimental.mx_to`](../../../../catlass/tla/experimental/__init__.py)

Description:

Convert tensor tiles to, from, or between microscaling formats.

The source and destination are UB tensor tiles. Use an ordinary `Tensor`
for dense `f16`, `bf16` or `f32` values and a `(payload, scale)` tuple
for MX values. The operation writes the conversion into the destination
and returns that same destination object.

Call this in `tla.vector()`. The bitcode path loops over the complete tile.
One- and two-dimensional tensors support strided rows or columns. Standard
two-dimensional blocked layouts, including `zN`, `nZ`, `zZMxScale`, and
`nNMxScale`, are supported by a general bitcode path. MX-to-MX conversion
can change the scale grouping axis. MX tile coordinates
must start on a 32-element group boundary. Contiguous packed FP4 tiles
must start on a byte boundary.
In conversions between dense and MX tensors, the dense tensor may have
different strides, including a different contiguous axis. Scale tensors
can use different strides from the payload tensors.
The general layout path stages individual groups and can be slower than
the contiguous and supported strided fast paths.
For runtime shapes, strides, or coordinates, the caller must ensure the
alignment requirements, matching payload shapes, sufficient scale extents,
and an even row stride for two-dimensional packed FP4 tiles. When a
blocked layout's grouping axis is inferred from runtime extents, that
axis must contain at least 32 elements.
For two-dimensional layouts the scale grouping axis must be identifiable
unambiguously from compile-time payload and scale extents. Source and
destination payload storage must not overlap each other or any scale
storage. Input and output scales may share storage if their views begin
at the same address. Destination layouts must map distinct logical
elements or scale groups to distinct storage locations. `VLn` masks select the first
n values in grouping order (destination groups for MX outputs, otherwise
source groups),
and `ALLF` selects none. Inactive payload elements are written as zero;
output scales are still written, and widening copies the input scales.
Other masks and
unsupported layouts raise an error. GM↔UB copies remain explicit.

Prototype:

```python
tla.experimental.mx_to(src: Tensor | tuple[Tensor, Tensor], dst: Tensor | tuple[Tensor, Tensor], *, round_mode: RoundMode = RoundMode.CAST_ROUND, mask: Any | None = None) -> Tensor | tuple[Tensor, Tensor]
```

Parameters:

- `src` (`Tensor | tuple[Tensor, Tensor]`): dense UB tile or MX
  `(payload, scale)` pair. Required.
- `dst` (`Tensor | tuple[Tensor, Tensor]`): destination tile or MX
  `(payload, scale)` pair. Required and returned unchanged.
- `round_mode` (`RoundMode`): payload rounding mode. Optional;
  defaults to `RoundMode.CAST_ROUND`.
- `mask` (`pattern | None`): `ALL`, `ALLF`, or a `VLn` prefix pattern.

Constraints:

- Must be called inside a `@tla.kernel` decorated function and directly
  inside `tla.vector()`, outside `tla.vec.func()`.
- At least one operand must be a `(payload, scale)` pair; dense-to-dense conversion is
  not an MX conversion.
- A dense source must target a `(payload, scale)` pair; an MX source may target a dense
  tensor or another `(payload, scale)` pair.
- MXFP4 destinations support `RoundMode.CAST_ROUND` only.

Example:

```python
with tla.vector():
    tla.experimental.mx_to(dense_ub, mx_fp8_ub)
    tla.experimental.mx_to(mx_fp8_ub, dense_out_ub)
    tla.experimental.mx_to(mx_fp8_ub, mx_fp4_ub)
```

## `tla.experimental.img2col`

**Source:** [`catlass.tla.experimental.img2col`](../../../../catlass/tla/experimental/__init__.py)

Description:

Load an L1 feature-map tile into L0A or L0B with img2col expansion.

Prototype:

```python
tla.experimental.img2col(dst: Tensor, src: Tensor, params: Img2colParams) -> None
```

Parameters:

- `dst` (`Tensor`): L0A `zN` or L0B `nZ` tile shaped `(M, K)`,
  where `(M, K)` is the expanded matrix window. The L0B path
  automatically arranges the data in `nZ`. The destination layout
  and coordinate specify the storage and window start. Required.
- `src` (`Tensor`): L1 feature-map tile, tagged `zNUnAlign`, which is the
  NC1HWC0 nesting `((h*w, 1), (C0, c1))`. Required.
- `params` (`Img2colParams`): Convolution geometry. Required.
  - `fmap_hw` (`tuple`): Feature-map `(H, W)` extents. Required.
  - `filter_hw` (`tuple[int, int]`): Filter `(kH, kW)`; compile-time
    integers. Required.
  - `stride_hw` (`tuple`): Stride `(sH, sW)`. Default `(1, 1)`.
  - `dilation_hw` (`tuple`): Dilation `(dH, dW)`. Default `(1, 1)`.
  - `pad` (`tuple`): Padding `(left, right, top, bottom)`. Default
    `(0, 0, 0, 0)`.
  - `pad_value` (`int`): Bit pattern of the padding fill value. Default `0`.
  - `repeat_load_stride` (`int`): Distance between successive source
    starts, in units of 16 elements along M or one source C0 along K.
    Default `0`.
  - `repeat_load_time` (`int`): Number of loads. Default `1`.
    `0` performs no load.
  - `repeat_load_axis`: `tla.experimental.height` along M or
    `tla.experimental.width` along K of the expanded matrix.
    Default `tla.experimental.height`.

Constraints:

- Must be called inside a `@tla.kernel`-decorated kernel function.
- Must be called inside `tla.cube()`.
- L0A and L0B support `f16`, `bf16`, `f32`, `i32` and `u32`.
  L0A also supports `i8`, `u8`, `hif8`, `f8e4m3fn` and `f8e5m2`.
- `src` and `dst` must share an element type.
- Source channels come from the NC1HWC0 source shape, independently of
  the destination K window. Source C0/C1 and destination K extent and
  K coordinate must be static. `filter_hw` must be compile-time integers.
- The source view must contain at least `H * W` spatial positions.
  If the source view contains multiple C1 slices, its C1 stride must
  equal `H * W * C0` elements regardless of the destination K window.
  A spatial crop of one C1 can use a source view containing just that slice.
- The K transfer length is the destination logical K extent rounded up
  to a source C0. The storage must fit that length. For example,
  8 FP32 channels can be loaded into L0B storage padded to 16 columns.
  The K start must align to C0 for L0A or 16 elements for L0B.
  Every K window, including the last load in a width repeat, must fit
  within the full K axis of the source channel/filter combination.
  Source channels and the K transfer length must fit in 1..65535.
  The destination K coordinate must fit in 0..65535.
- The destination M extent and coordinate must be in 0..65535
  and 0..32767, respectively.
- `fmap_hw` entries must be in 1..32767, stride entries in 1..63,
  dilation entries in 1..255, and padding entries in 0..255. The
  compiler checks static values. Runtime values must satisfy the same
  constraints.
- Filter extents are compile-time integers in 1..511.
- `repeat_load_stride` and `repeat_load_time` must be compile-time
  integers in 0..65535 and 0..255, respectively. Omitting all three
  repeat-load fields performs a single load.
- The destination layout supplies the outer fractal stride (along K for
  L0A or M for L0B), including for a view into a parent matrix. Its byte
  stride must be a positive multiple of 512 and fit in an unsigned
  16-bit field in fractal units.
- Effective addresses, including any tensor coordinates and pointer
  offsets, must align to 32 bytes for L1 and 512 bytes for L0A or L0B.
  The caller must ensure this alignment for runtime addresses.

Example:

```python
with tla.cube():
    # l1_fmap holds NC1HWC0; l1_filter holds the (K, N) weight matrix.
    tla.experimental.img2col(l0_a, l1_fmap, tla.experimental.Img2colParams(
        fmap_hw=(hi, wi), filter_hw=(3, 3), pad=(1, 1, 1, 1)))
    tla.copy(l0_b, l1_filter)
    tla.mmad(l0_c, l0_a, l0_b, init_c=True)
```

## `tla.experimental.exp_sub`

**Source:** [`catlass.tla.experimental.exp_sub`](../../../../catlass/tla/experimental/__init__.py)

Description:

Compute `exp(float(lhs) - float(rhs))` with the native ExpSub
instruction. Accept f16 or f32 inputs and return f32 values.
This experimental API may change or be removed without
backward-compatibility guarantees.

Prototype:

```python
tla.experimental.exp_sub(lhs: VectorSSA, rhs: VectorSSA, *, reg_slot: RegSlot = RegSlot.ZERO, mask: MaskSSA | None = None) -> VectorSSA
```

Parameters:

- `lhs` (`VectorSSA`): FP16 or FP32 input. Required.
- `rhs` (`VectorSSA`): Input register with the same element type and
  physical width as `lhs`. Required.
- `reg_slot` (`RegSlot`): Chooses the input position `j` used in both
  `lhs` and `rhs` for each output position `i`. Indices start at zero.
  If position `j` is valid and enabled by the mask, the output at `i`
  is `exp(float(lhs[j]) - float(rhs[j]))`. For FP16 inputs, `ZERO`
  uses even positions (`j = 2*i`) and `ONE` uses odd positions
  (`j = 2*i + 1`). With `ONE`, the results for input positions 1, 3,
  and 5 go to output positions 0, 1, and 2, respectively. For FP32
  inputs, both values use `j = i`. Defaults to `RegSlot.ZERO`.
  Keyword-only.
- `mask` (`MaskSSA | None`): Optional mask over input element positions.
  Defaults to `None`, which enables all positions within the valid input
  range. Keyword-only.

Constraints:

- Must be called inside a `@tla.kernel` and `tla.vec.func(mode="simd")`.
- Both inputs must have the same FP16 or FP32 element type. A known
  valid element count limits an input to that many leading positions.
  When both counts are known, use the smaller count.
- The output contains 64 FP32 elements.
- An output position receives positive FP32 zero (ZEROING) if its
  input position is outside the valid range of either input or is
  disabled by the mask. This applies even to nonfinite input values.
  With only the first FP16 input element valid, `RegSlot.ONE`
  returns all zeros.
- Scalar and SIMT forms, other input types, other register slots,
  and merging masked results are unsupported.

Example:

```python
with tla.vec.func(mode="simd"):
    even = tla.experimental.exp_sub(lhs_half, rhs_half)
    odd = tla.experimental.exp_sub(
        lhs_half, rhs_half, reg_slot=tla.params.RegSlot.ONE
    )
    result = tla.experimental.exp_sub(lhs_float, rhs_float, mask=None)
```
