# CATLASS Python Language Reference

Start with the [API Quick Reference](../quick_reference.md) to choose an API by task and execution context. This document is the **CATLASS Python language reference** (typically imported as `import catlass.tla as tla`). It covers values and types, layout and tensor, data movement, compute, synchronization, resources, and debug printing. Compilation, launch, and Host tensor binding are in the [Program Lifecycle Reference](../runtime/index.md); environment variables are in [Environment Variables](../../kernel_development/core_concepts/env_vars.md).

Interface descriptions and examples come from each op's source docstring (`Directory:` plus `Description:` / `Parameters:` / `Constraints:` / `Example:`).

Unless an entry explicitly allows Host use, these APIs must be called inside a `@tla.kernel`-decorated kernel function body. For example, `tla.arch.get_capacity_in_bytes` is also available on the Host.

The vector unit has two execution modes, and they are separate chapters below. **SIMD Vector Compute** is the default: whole vector registers over data staged in UB, for regular dense work. **SIMT Vector Compute** is one thread per element addressing memory by index, for work too irregular or scattered for tiling to pay off. A number of scalar APIs behave differently depending on which mode encloses them -- element access and the scalar arithmetic / compare / select / conversion ops all emit a per-thread op inside a SIMT region, and each entry says so under `Constraints:`.
